Ledger Atlas

A clean-room, local-first personal-finance product. Money Manager files are import inputs, never the product’s internal data model.

What exists

An unaccepted Swift implementation candidate: exact money and time handling, immutable SQLite classification, staging, loss accounting, atomic/idempotent persistence, a redacted mmctl inspect/coverage/stage/reconcile surface (no CLI write), a synthetic-profile import workspace, LedgerApplication commands including export/restore, and a native Mac journey that can approve a synthetic source and edit the imported ledger.

Compatibility promise

No universal compatibility claim. The observed Android v19 SQLite profile is classification-only. The positive adapter is a synthetic text-safe test subset, not a certificate for the real 19-table/non-text format. mmctl cannot write a canonical ledger.

Still required

A gated baseline commit; evidence-backed real-v19 mapping; a shipped daily-finance workbench; iOS client; analytics; sync; and production migration support.
