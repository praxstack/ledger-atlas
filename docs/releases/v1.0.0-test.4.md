# Ledger Atlas v1.0.0-test.4 (test build)

The fourth test build of the Mac app. It is signed ad hoc and not notarized, so macOS asks you
to approve it once: see the
[install guide](https://github.com/praxstack/ledger-atlas/blob/main/docs/INSTALL.md). If an
earlier test build is installed, drag this one over it; your ledger and settings stay.

## New since test.3

- **Hide amounts (⇧⌘H).** Every figure on screen becomes the same row of bullets, whatever its
  size or sign; charts keep their shape and VoiceOver says "Amount hidden" (#219). Exports
  (including CSV) and an entry form you have open still show the real amounts.
- **Export to CSV.** File › Export › CSV of This View saves the transactions you are looking at,
  ready for a spreadsheet (#227).
- **Recovery key.** An imported ledger's backup now opens on another Mac. On the first Mac, go to
  Backup › Save recovery key… and keep the `.ledgerkey` file apart from your backups. On the other
  Mac, open or restore the backup and pick Choose Recovery Key… when asked. When the key is
  missing, the app now says so plainly instead of calling the ledger damaged (#217).
- **Safer after a crash.** A ledger cut off mid-save (a crash or power loss), or one restored
  from a backup, now opens and rolls back the unfinished save instead of being refused (#217).
- **Upcoming.** Recurrence shows everything due in the next 30 days, grouped by day, with
  overdue items first and In/Out totals. The daily reminder opens the entry form with Upcoming
  beside it (#228).
- **Debit cards import correctly.** Spending on a Money Manager debit card now moves the bank
  account that pays it, so bank balances match Money Manager (#223). This applies to new
  imports only: to get the corrected balances, import your backup again into a new ledger.
- **Get Started.** A screen of first steps, each one click away: bring over your history, log
  new spending on the Mac, set a budget, make a backup and lock the app. "From today, log on the
  Mac. Re-importing newer phone backups arrives in January." The first step shows as done only
  when the open ledger came from an import, and stays done while you edit (#216).
- **More of the new look** (#216, #221, #222):
  - Transactions shows a Money in / Spending / Net line, with the net figure largest.
  - Categories show this month's amount and a share bar; Transfers are grouped by month with
    both accounts' colours; Tags show how often each is used.
  - Cards have a fine border and soft shadow in light mode, links use the app's teal, and
    amounts are formatted everywhere (₹ with Indian grouping).
  - Light mode on macOS 26 no longer shows a white strip under the toolbar or behind the
    sidebar, and text fields and progress bars read more clearly.

## Known limits

- The widget and Shortcuts are off in ad-hoc builds (they need an Apple Team ID).
- Backups made by the app are plain SQLite files; keep them somewhere private.
- Portable packages and the reopen at launch don't offer Choose Recovery Key… yet (#225). Use
  File › Open Ledger… to get it.
- Ledgers imported with an earlier test build keep the old debit-card balances; re-import to
  fix them (#223).
- The first import of a phone-sized backup (about 7,500 entries) takes about 2 to 3 minutes.

## Checked before release

The shipped DMG ran on a CI Mac: it opened, walked every screen, imported a 7,500-entry made-up
backup and reopened the resulting ledger without errors. The release was published only after
the full CI run on the same commit passed.
