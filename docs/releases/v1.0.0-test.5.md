# Ledger Atlas v1.0.0-test.5 (test build)

The fifth test build of the Mac app. It is signed ad hoc and not notarized, so macOS asks you to
approve it once: see the
[install guide](https://github.com/praxstack/ledger-atlas/blob/main/docs/INSTALL.md). If an
earlier test build is installed, drag this one over it; your ledger and settings stay.

## New since test.4

- **Bulk edit.** In Transactions, select many entries (⌘-click, ⇧-click or ⌘A, or Select All for
  everything the filter shows). While editing, set their category or add or remove a tag in one
  step. The confirm sheet says exactly what changes. Afterwards, **Revert This Bulk Change** (also
  Edit › Revert Bulk Change) puts everything back. A tag reaches every part of a split, both legs
  of a transfer and its fee, and every installment payment. A category can't be set on splits or
  transfers, so those are refused or skipped. Anything that can't change is named with a reason
  before anything is written (#232).
- **Large ledgers upgrade.** A ledger over 512 MB (a full phone history with receipts can be
  about 900 MB) can now move to a new version of the app's file format; before, it was refused.
  The app first checks there is enough free disk space and changes nothing if there isn't (#231).
- **More of the new look** (#229, #218):
  - Accounts show an icon for each type (card, cash, wallet, saving, loan and so on), and row
    actions are a single ⋯ menu on Accounts, Categories, Recurring, Budgets and Tags.
  - Search results look like Transactions rows, grouped by day.
  - Backup says plainly which backup fits your ledger (a portable package, or a 1:1 backup when
    it has receipts or is large); Receipts has a drop zone with
    Add receipt…; Local Access shows Running or Stopped; the lock screen's passcode field is
    easier to see, and Touch ID has its symbol.
  - The import balance receipt is more compact.

## Known limits

- The widget and Shortcuts are off in ad-hoc builds (they need an Apple Team ID).
- Backups made by the app are plain SQLite files; keep them somewhere private.
- Portable packages and the reopen at launch don't offer Choose Recovery Key… yet (#225). Use
  File › Open Ledger… to get it.
- Ledgers imported with an earlier test build keep the old debit-card balances; re-import to
  fix them (#223).
- Bulk edit can't delete entries yet.
- The first import of a phone-sized backup (about 7,500 entries) takes about 2 to 3 minutes.

## Checked before release

The shipped DMG ran on a CI Mac: it opened, walked every screen, imported a 7,500-entry made-up
backup and reopened the resulting ledger without errors. The release was published only after
the full CI run on the same commit passed.
