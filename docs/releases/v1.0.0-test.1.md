# Ledger Atlas v1.0.0-test.1 (test build)

The first test build of the Mac app, for trying out on your own Mac. It is signed ad hoc and
not notarized, so macOS asks you to approve it once: see the
[install guide](https://github.com/praxstack/ledger-atlas/blob/main/docs/INSTALL.md).

## What is in it

- **New look.** Brand identity, app icon, design tokens, a grouped sidebar with account
  balances, a welcome screen, and new Overview, Transactions (with inspector), Accounts and
  Budgets screens. The remaining screens are still on the old look and will follow.
- **Import your Money Manager backup.** Click **Import Money Manager Backup…** in the toolbar,
  **File › Import Money Manager Backup…** (⌘⇧I), or the link on the empty screen. Choosing a
  `.mmbak` file from **Open Ledger** now offers to import it instead of failing.
- **Insights.** Month and year statistics, category drill-down, trend, and PDF statements.
- **Settings.** Choose where the passcode and receipt keys are kept (private key file by
  default; Keychain optional).
- **Faster import.** About a third faster than before. A phone-sized backup (about 7,500
  entries) still takes about 4 minutes on a Mac, with progress and elapsed time shown.

## Fixed since the last test DMG

- "Widget status could not be published. Ledger could not be opened." no longer appears. The
  widget cannot run in an ad-hoc build, and that no longer blocks opening a ledger.
- `.mmbak` files are now selectable in the file panel.
- Import is reachable from the toolbar, the File menu and the empty states.

## Known limits

- The widget and Shortcuts are off in ad-hoc builds (they need an Apple Team ID).
- Backups made by the app are plain SQLite files; keep them somewhere private.
- The first import of a large backup takes a few minutes.

## Checked before release

The shipped DMG itself ran on a CI Mac: it opened, walked every screen, imported a 7,500-entry
made-up backup and reopened the resulting ledger without errors.
