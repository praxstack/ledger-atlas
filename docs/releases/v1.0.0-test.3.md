# Ledger Atlas v1.0.0-test.3 (test build)

The third test build of the Mac app, and the first with the new look on every screen. It is
signed ad hoc and not notarized, so macOS asks you to approve it once: see the
[install guide](https://github.com/praxstack/ledger-atlas/blob/main/docs/INSTALL.md). If an
earlier test build is installed, drag this one over it; your ledger and settings stay.

## What's new (Pro look, part 3, from #177)

- **Every remaining screen gets the new look.** That covers Insights, Categories, Tags & Memos, Recurring, Installments, Transfers, Search, Receipts, Backup, Local Web Access, the lock screen and Import Review. All of them now use the same cards, badges, status lines and action bars as Overview and Transactions.
- **Insights, rebuilt.** The period figures sit on top, followed by category cards with a colour key, a share bar and indented subcategories. The trend chart has income in green and spending in ink, never a second blue, and VoiceOver reads the chart month by month.
- **Lock screen.** It's a centred card with a large Unlock button.
- **Import Review.** The screen shows one decision card that says whether the backup can be imported, then the redacted details and the actions. After an import, the balance-match receipt sits on top.
- **Backup.** It's split into clear sections: this ledger, 1:1 backups and portable packages.
- **Empty and loading states.** Every screen has one, and when a screen is empty it offers "Begin editing" if the ledger is open.

## Fixed

- With Full Keyboard Access, Tab no longer crashes the app on the Receipts list.
- Tab no longer lands on hidden, unnamed links on Overview.
- VoiceOver reads every row on Receipts. Before, the screen made the window taller than the display.

## Also new since test.1

These shipped in test.2, which went out without notes.

- **UI polish** across the app (#176). The Appearance setting now switches the whole app to
  Light or Dark (#165).
- **Balance-match receipt after a Money Manager import** (#206): after an import, you see how
  each account's balance compares with the backup.
- **Memo memory** (#215): the entry form suggests the account and category from an earlier
  entry with the same memo.
- **One window**: the app keeps a single main window, quitting waits for a running save to
  finish, and Erase transactions works on imported ledgers (#210).
- **Architecture review fixes** (#208): certification and daylight-saving fixes.
- **Privacy check** (#167): tests confirm that no ledger data reaches the console, logs, stray
  files or the network.

## Known limits

- The widget and Shortcuts are off in ad-hoc builds (they need an Apple Team ID).
- Backups made by the app are plain SQLite files; keep them somewhere private.
- The first import of a phone-sized backup (about 7,500 entries) takes about 2 to 3 minutes.

## Checked before release

The shipped DMG ran on a CI Mac: it opened, walked every screen, imported a 7,500-entry made-up
backup and reopened the resulting ledger without errors. The release was published only after
the full CI run on the same commit passed.
